# Memory write

Before FINAL, self-check reusable facts. A stable role, responsibility, collaboration style,
preference, principle, decision, or delivery that a later turn would need is reusable. When any
such fact was established, write long-term memory before FINAL. A completed answer that leaves
long-term memory unchanged after reusable facts is a missed write.

Route softly:

- Stable across groups, and not a dated deed → `people/`
- Dated decision or delivery → `events/`
- A theme of the group, not one person → `group_profile`

Budget and replace stay in force. The `write_discipline` and `profile_budget` modules, when
present, are assembled beside this file in filename order. Prefer replacing or tightening an
existing note over appending a parallel one. Do not grow a surface by stacking episodes, and do
not extend a full profile past its budget.

Reads of one `scope_id` stay serial (`concurrency` 1). This module does not add a second promote pass.
