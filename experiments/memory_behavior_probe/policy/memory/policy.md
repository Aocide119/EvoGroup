# Memory component

Long-term memory is a navigation layer over group evidence, not a second source of truth.
Verify claims against original records. Three soft surfaces:

- `people/` — cross-group abstract portraits
- `events/` — dated decisions and deliveries
- `group_profile` — group-level themes

Read to orient. Write only facts a later turn can reuse. Writes are soft policy: no access
blocks and no separate promote round. The write module says when to record them before FINAL.
