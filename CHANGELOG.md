# Changelog

## 0.1.0

- CLI for importing and querying shared group conversations.
- Five scoped tools, stable source citations, bounded interaction and pre-feedback reflection.
- Optional user/business feedback with explicit unjudged and incident categories.
- Progressive trace disclosure, evidence-validated diagnoses and bucketed findings.
- Four declarative revision interfaces, stale-plan checks, validation records and rollback.
- Explicit offline demo, synthetic regression tests and release packaging.
- Bilingual documentation with method, results, framework and component-ablation figures.
- EverMemBench and GroupMemBench evaluation with official scoring, episode selection,
  per-question memory isolation and paired candidate validation.
- Source timestamps retain their original offsets while SQLite ordering remains UTC-stable; search
  covers sender, dates, IDs, reply links and visible metadata.
- Output-contract and budget failures are retained as diagnosable experiences, with provider and
  tool failures classified separately; trace evidence rejects empty ranges and non-standard JSON
  Pointer indexes.
